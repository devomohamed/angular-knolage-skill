Follow `AGENTS.md` as the shared engineering contract. Read the relevant
skill in `.claude/skills/` before specialized work. Canonical skill
sources live in `.agents/skills/`.

Before editing, inspect the codebase and existing patterns. Ask only for
missing information that materially changes the implementation. Preserve
current behavior, avoid unrelated refactors, and validate changes with
available project commands.

production/shared data without explicit user approval. Report what you
actually inspected, changed, and tested.
